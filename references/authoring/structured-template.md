# 结构化解读模板

适用：哲学书、电工教材、现代论著、通用文本。方向模块：**哲学 / 电工 / 通用（默认）**。
特征：**结构化解读**——章节脉络 + 论证骨架 + 关键段细读。

---

## 精读文档结构

```
# 《书名/篇名》精读

## 全书定位
（作者、思想背景、该书在学科/作者作品中的位置、写作缘起）

## 章节地图
（全书结构一览：章节 → 核心问题 → 与前后章关系）

## 章节解读
（每章重复以下结构）
```

### 每章结构

```
### 第 N 章：〈章名〉

**章节脉络**
（本章主线：要解决什么问题、推进了什么）

**论证骨架**
（论点 → 论据 → 论证过程，可画推理拓扑/逻辑链）

**关键段落细读**
（选 2-5 段最重要原文，逐段拆解：表层意思 → 论证功能 → 隐含预设）

**概念提取**
（本章新概念 → 概念页；与旧概念的关联/冲突/修正）

**学者评价**
（anysearch 检索学界讨论，注明来源）
```

## 方向变体

### 哲学变体（齐泽克等）
- 每章加 **思想谱系** 节：该观点与前辈（黑格尔/拉康/马克思）、同代、后学的关系
- 概念提取时关注**术语翻译差异**（如 interpellation/询唤），维护中英对照

### 电工变体（教材）
- 每章加 **公式与原理** 节：公式推导、物理意义、适用条件、典型应用、**易错点**
- 保留图表/电路图说明；术语卡对齐国标

### 通用默认
- 按基础结构即可，学者评价节可放宽为"相关背景资料检索"

## 收尾

```
## 全书总结
（跨章串联、全书论点收束、与外部知识的连接）

## 概念页清单
（本书提取的概念 → 已建/待建 wiki/concepts 页）

## 遗留疑问
（待澄清的问题，供重读/答疑使用）
```
