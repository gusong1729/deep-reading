# 精读格式系统（Reading Format System）

> 核心规则：精读的最小合格单位是“原文/材料段在上 + 对应精读段落群在下”。没有原文或材料锚点，不是精读；只有摘要和启示，最多是导读草稿。

## 方法校准来源

- 历史 close reading：要慢读、多次读，分别处理“说了什么、为什么这样说、如何回答问题”。参考 BYU History Close Reading：https://history.byu.edu/close-reading
- 哲学 close reading：重点解释文本、词语、定义，分析哲学家如何提出主张并提供论证。参考 University of Guelph Philosophy Close Reading：https://guides.lib.uoguelph.ca/c.php?g=130967&p=5003050
- 技术/电工排查：安全优先，先 LOTO/验电，再检查接线、测电压/压降、隔离故障。参考 AnySearch 检索到的电气排障步骤资料（CalcPanel/TPC Training 等）。

这些来源只用于校准格式，不替代具体文本本身。执行时仍以用户材料、原文和现场安全规范为准。

## 0. 通用型格式

适用：用户未指定领域，或材料是现代论述、说明文、教材、报告、文章。

### 最小合格单元

```markdown
### 原文段 N：段落主题

> 原文/材料照录。段落太长可节选，但必须标明“节选”，并说明节选范围。

这段先要读通的是……这里不要急着提炼观点，而要把句子内部的主语、动作、对象和转折关系讲清楚。读者读完这一段，应该知道原文到底说了什么，而不是只记住我的概括。操作化建议：先用自己的话复述这段，再继续读下一段。

这段真正起作用的地方在于……它承接前文的哪个问题，又把后文推向哪个方向。这里要解释文本的推进功能，而不是把它孤立成一句名言。操作化建议：读任何段落时，都在旁边写一句“它解决了前面哪个问题”。

这里最容易读错的是……如果某个关键词、限定词、转折词被忽略，整段意思会偏到哪里。警告要具体，不能泛泛说“注意不要误解”。操作化建议：遇到“但是、所以、并非、只有、必须”这类词，先圈出来看逻辑。

这一段可以带走的判断是……这个判断必须从原文证据长出来，不能跳到外部感悟。操作化建议：只保留能被原文支撑的判断。
```

### 代码/材料照录规则（技术教材、手册、教程类材料）

代码照录保留注释与输出标注，不加行号；代码的完整含义包含运行语境（导入、依赖、版本、解释器状态），照录时若材料省略 import/依赖等样板，须在精读中说明，必要时指出补全后能否运行。材料中图片公式/图表无法转录时，照录位置标注占位（如 "[公式图，epub 文本缺失]"）并说明缺失对理解的影响，不得悄悄跳过公式导致数字悬空。

**代码块与讲解文字的原文段处理**：教程类材料常出现"代码 1 + 文字解释 1 + 代码 2 + 文字解释 2"的微观交错体。精读时按"完整示例单元"切分——一组代码块及其紧邻的讲解文字作为一个"原文段 N"照录；不必把代码和讲解拆成两个原文段。原文段标题命名以"示例/教程主题"为单位（如"装饰器基础结构""带参数装饰器工厂"），不按"代码""讲解"切分。

**操作化建议长度约定**：每段末尾的"操作化建议"默认一句（一个具体动作）；若原动作需要多步才能完成，独立成段但保持简短（≤3 步），不展开成教程；超过 3 步应回到解读段内嵌入说明，避免建议段膨胀。

### 通用验收

- 原文在场。
- 每段解读至少包含句意、上下文、误读点、可带走判断。
- 不用"核心观点列表"替代段落展开。
- 如果只是总结全文结构，状态标为"导读草稿"。
- 材料核验（技术/手册/教程类材料必做）：(1) 示例能否运行（补全 import 与依赖后验证，含变量名一致性与缩进逻辑）；(2) 时间状语（定义时/运行时/导入时）是否与语言规范一致；(3) 关键表述（如执行顺序）有无歧义；(4) 材料内部是否自相矛盾；(5) **数字可复算性**——带数据表与结论数字的案例（概率、指标、统计），用表中数据独立重算，不可复算必须标注差异并给出重算结果（例：表中 6 人数据三种口径复算均不等于书中结论 0.5658，最接近为 9/16=0.5625）；(6) **概念定义一致性**——核心概念定义与标准定义不符时明确指出差异及后果（例："独立=影响等值"是偷换定义，独立的标准定义是 P(A,B)=P(A)P(B)，朴素贝叶斯的独立是类条件独立，特征贡献并不等值）；(7) **史实/事实宣称核验**——教材中的历史宣称（谁发明/哪一年/第一台/量级数字）须对照权威资料核验，与权威表述有出入时标注"通行表述 vs 精确表述"差异，不以教材权威照单全收。核验姿态：基础教材的简化（称号化/括号化/量级化）是合理教学手段，精读标出简化边界即可，不是攻击作者。例："ENIAC 是第一台真正意义上的电子计算机"精确为"第一台通用电子数字计算机"（ABC/Colossus/Z3 更早存在）；"微处理器（SoC）"是两个不同层次概念被括号误等——1970s 只有微处理器（Intel 4004），SoC 是 1990s 后概念；"超算 TFLOPS 甚至更高"在 2020s 已过时，实际达 PFLOPS/EFLOPS 级。发现瑕疵在精读中明确指出，不以教材权威为由照单全收；技术术语首次出现同样给括号注释。(8) **概念负荷审计**——核心概念首次出现时是否给出操作性定义；若未给出，需审计该未定义概念是否在论证骨架中承担分类基准 / 价值判断 / 因果起点等承重角色。带立场文本中常见"未定义直接承担核心断言"——这属于论证结构问题（负担词论证），与第 6 项"定义准确度"是两个不同修复路径。第 6 项管"定义与标准是否对齐"；第 8 项管"未定义就承担论证"。——第19轮《白色女权报告》精读发现并沉淀。

**材料核验发现的瑕疵处理姿态**：核验发现的瑕疵以 callout（`> [!warning]`）就地标注，写明"底本此处 X，规范/原文应为 Y，差异后果 Z"；若一段内瑕疵超过 3 处，单开"材料瑕疵清单"小节集中汇总，避免 callout 淹没解读段。核验不等于攻击作者，措辞保持"标出简化边界"，不写"作者错了"。

### 数字可复算性的排序建议与差异分级（第 23 轮沉淀）

> 适用：所有带数据表与结论数字的精读（概率、统计、机器学习、经济指标等）。第 23 轮（2026-08-26）桑园《Python 机器学习入门与实战》§7.2.1 朴素贝叶斯"p(失恋|唱歌跳舞×办公室人员)=0.5658"实战验证沉淀。

执行第 (5) 项"数字可复算性"时，两条落地动作：

- **(a) 重算结果建议排序**：按"最接近书中断言"的口径优先呈现，再用其他口径补充。读者优先看"哪种合理口径最接近 0.5658"。本轮实例：直接频率 0.5、朴素贝叶斯标准 0.375、朴素贝叶斯两两归一化 0.6——三种口径中两两归一化（0.6）最接近 0.5658，但**仍不重合**。呈现顺序：(1) 先标出最接近的口径 → (2) 给出该口径的具体数字 → (3) 列出其他口径供对照。
- **(b) 差异处理姿态分级**：把"重算结果 vs 书中断言"的差异按大小分级，决定 callout 措辞强度——
  - **差异 < 0.01**：教材简化边界（合理）。用中性 callout 标"重算结果 X 与书中断言 Y 接近，差异 Z < 0.01，属教材合理简化"，不写"作者错了"。
  - **差异 0.01-0.05**：翻译级瑕疵（标 warning）。用 callout `> [!warning]` 标"重算结果 X 与书中断言 Y 差异 Z (0.01-0.05)，属翻译级瑕疵（教材口语化或中间步骤省略）"，写明"差异原因可能是(a) 口语化转译 / (b) 中间步骤省略 / (c) 其他"——但**不**直接归咎作者。
  - **差异 > 0.05**：作者计算错误（标 critical）。用 callout `> [!error]`（如有）或强化 warning 标"重算结果 X 与书中断言 Y 差异 Z > 0.05，可能为作者计算错误，请核对原始底本或换源"。这种差异少见，但若出现必须升级处理。

### 翻译级瑕疵的两种类型与典型示例（第 23 轮沉淀）

> 适用：所有"教材口语化 vs 标准定义"差异的精读。第 23 轮"边际独立 vs 类条件独立"实战沉淀。

执行第 (6) 项"概念定义一致性"时，两条落地动作：

- **(a) 翻译级瑕疵的两种类型**：当核心概念定义与标准定义不符时，区分两种类型——
  - **类型 1：教材口语化（合理简化）**——差异是口语化转译严格数学概念，但不影响后续公式推导。归为"合理简化"，用中性 callout 标"教材口语化承担严格数学概念"。
  - **类型 2：作者错误（不一致）**——差异导致后续公式推导与文字描述矛盾。归为"翻译级瑕疵（不一致）"，用 warning 标"教材文字描述与公式推导矛盾"。
- **(b) 典型示例：边际独立 vs 类条件独立**——
  - 边际独立（严格定义）：P(A, B) = P(A) × P(B)——两个事件在所有上下文中都不影响彼此。
  - 类条件独立（朴素贝叶斯实际用的）：P(F1, F2 | C) = P(F1 | C) × P(F2 | C)——特征在给定类别后独立。
  - 教材"互相独立"是边际独立的口语化表达，但教材公式实际做的是类条件独立——这是类型 1 的典型。
  - 操作化建议：读任何朴素贝叶斯教程段，第一句话就要问"作者用的'独立'是哪一种独立？边际独立还是类条件独立？"——两者在公式里是同一个式子但语义不同。

### 概念负荷审计："延后定义"vs"前置定义"（第 23 轮沉淀）

> 适用：所有精读中的"核心概念首次出现"识别。第 23 轮朴素贝叶斯"朴素"二字实战沉淀。

执行第 (8) 项"概念负荷审计"时，两条落地动作：

- **(a) "延后定义"vs"前置定义"的区分**：
  - **前置定义**：概念在公式推导前被定义——读者读公式时已知道概念是什么。
  - **延后定义**：概念在公式推导中被首次使用，但定义被推到后续（如"提示""小贴士""补充说明"）才给——读者读公式时**不知道**该概念是什么。
- **(b) 教材口语化"延后定义"作为合理简化边界**——延后定义不等于错误。教材常用"提示""小贴士""补充说明"把核心定义延后（因为正文要讲公式推导，不能打断），这是合理简化。但读者按"前置定义"的标准识别这种延后，会在精读中标注"未定义就承担论证"——这是**读者的核验动作**，不是攻击作者。本轮朴素贝叶斯"朴素"二字属于延后定义，教材在 §7.2.1 末尾"提示 由贝叶斯到朴素贝叶斯"中才点出定义，**合理简化但需要标注**。

### 操作化建议的算法语境变体（第 23 轮沉淀）

> 适用：所有计算机/算法/统计/概率教材的精读。第 23 轮朴素贝叶斯实战沉淀。

通用型格式的"操作化建议"模板默认是论述型（"先用自己的话复述""读任何段落时在旁写一句它解决了前面哪个问题"）。但对算法/统计语境，这些论述型动作**意义不大**——读者更需要"用表里数据独立复算""检查'独立'是边际还是类条件"这种**算法验证型动作**。算法语境变体的三步走：

- **(a) 标类别与特征**——本段有 3 类（失恋、升职加薪失败、谈成生意惊喜）、3 个特征（表现、职业、喝酒原因）。朴素贝叶斯一般对**特征做类条件独立假设**，但**类别之间不独立**——读者必须分清"哪个维度被假设为独立"。
- **(b) 用表里的数据独立复算**——按朴素贝叶斯公式（P(C|F1,...,Fn) = P(C) × Π P(Fi|C) / P(F1,...,Fn)）算出作者给的数字。如果算不出**别**接受作者给的数字——本段 0.5658 就是用三种合理口径都算不出的典型，按 §0 第 (5) 项应标出"重算结果 X 与书中断言 Y 差异 Z"并给出重算值。
- **(c) 检查"独立"是边际独立还是类条件独立**——按 §0 第 (6) 项**两者是不同的**。教材口语化用"互相独立"时，多半实际指类条件独立；读者按字面理解（边际独立）会得出比朴素贝叶斯更强的假设。原文段只要写出 p(F1, F2|C) = p(F1|C) × p(F2|C) 这种公式，就是类条件独立——文字措辞的简化是教材"以例说理"的常见边界，**不**算作者错了。

### 跨格式通用精读姿态：比喻/类比的可替换性

哲学格式 §3 已沉淀"例证四类（定义装置/应用演示/挑衅性套用/修辞性套用）+ 可替换性标尺"。这条判断不仅适用于哲学——任何领域的精读遇到比喻、类比、生活化例子时，都要问："这个比喻/类比能解释到什么程度？剩下的什么它解释不了？"判断标尺：**删掉比喻/例子的论证是否还成立**——如果删掉后论证仍成立，说明例子是修辞性的，不承担论证功能；如果删掉后论证塌了，说明例子是承重的，必须展开分析。这条跨格式通用姿态应沉淀在通用型末尾，而不是只挂在哲学格式里。执行示例：技术教程的"装饰器是给函数穿外套"——外套比喻解释了"附加功能不侵入原函数"，但没解释"装饰器在定义时替换名字绑定"；后半段是承重事实，必须补出，不可只用比喻搪塞。

### 跨格式通用精读姿态 2：修辞辨认（rhetorical awareness）

> 第19轮（2026-08-25，底本《白色女权报告》）沉淀。本质上从哲学 §3 + 历史 §1 共同的"修辞处理动作"里抽出，但只在带立场文本里用得最多，所以在通用型末尾也沉淀一条以备调用。

任何文本都可能用到修辞辨认，但批判性/带立场文本最关键。一句话里中性词和评价性词以高密度混合，是带立场报告体的典型特征。修辞辨认处理的是**评价性词与中性叙事词的等级分离**，加上识别修辞承担论证还是证据承担论证：

- **评价性词按强度分级**——强负面定性词（"危害巨大""蓄意颠覆""温床"）、中度评价词（"激进""精心包装""极端目标"）、轻度框架词（看似中立但承担分类功能，如"境外势力""代理人女权"）、中性叙事词（人名、机构、活动名）。读者看到这种分级才知道作者在哪一句用了评价、哪一句是事实。
- **暴露句式辨认**——"打着 X 旗号 / 实质上却是 Y""看似 X / 实则 Y"是政治报告体的标志性装置。它的修辞功能是先承认一件事有表面特征，再用一句转折词暴露其"真正目的"，引导读者"站到作者一边看"。测试标尺：删掉暴露词，句子是否还成立。如果不成立，说明修辞承担论证而非证据承担论证。
- **修辞承担论证 vs 证据承担论证**——修辞承担论证是用词选择让读者得出结论；证据承担论证是用具体事实让读者得出结论。区分这两者是精读批判文本的基本动作。
- **跨域应用**：通用型/历史/电工/哲学都可能用到这条——历史文本中"史臣笔法"（褒贬字暗示）就是修辞辨认；哲学文本中"反讽是否被加重"也是修辞辨认；电工手册中"重要警告用粗体"也是修辞辨认（虽然比较弱）。修辞辨认不只属于带立场文本，但只在带立场文本里它成为核心动作。

## 1. 历史风格格式

适用：史书、史料、编年体、纪传体、制度史、历史论文，《资治通鉴》优先使用本格式，并同时遵守 `historical-source-close-reading.md`。

### 最小合格单元

```markdown
### 原文段 N：事件/判断主题

> 原文照录。

这段首先交代的是谁在什么时间、什么位置、因为什么做了什么。历史精读的第一步不是悟道，而是把人、事、时读准；主语、官名、地名、军队数字、年号一旦错，后面的判断都会塌。操作化建议：读完先在边上写出“人—事—时”三项。

这段里的关键词是……这里解释官名、制度、礼制、名物、异名、避讳和古今义。解释不能离开本段，例如“推恩令”不是抽象制度名，而要说它在这里如何把削藩从强制动作改成恩惠程序。操作化建议：遇到制度词，先问它改变了谁的权力边界。

司马光把这段放在这里，是为了让它和前后事件互相照明。这里要说明它承接了前面哪场危机，又为后文哪种后果蓄势；编年体不是流水账，排列本身就是判断。操作化建议：读《通鉴》时，每段都问“前一条为什么不是别的事”。

从礼/分/名看，这段触动的是……这里要把文本事实落到秩序判断上。礼是行为和制度的正当形式，分是位置与权责的边界，名是身份和称谓的可预期性；不要空喊框架，要指出具体哪一句显示了越礼、失分或名不正。操作化建议：给每段标一个主轴：礼、分、名，或三者都不触发。

如果有史论句或臣光曰，必须转入“史论专读”，不能只摘一句当金句。操作化建议：看到“臣光曰”，先停下读论证，不要急着继续事件线。
```

### 臣光曰/史论专读单元

```markdown
> 臣光曰：……

司马光这段话的前提是……他先假定什么秩序是正的，再指出事件中哪里偏离。这里要把前提说清，因为前提不同，评价就会不同。操作化建议：先找司马光没有明说但已经默认的标准。

他的推理是……这一步要讲出论证链，不是翻译句子。比如他为什么从一个门名推出巫蛊之祸，为什么从李广治军推出“才可用而法不可学”。操作化建议：把臣光曰改写成“因为……所以……”链条。

这段与卷一“礼/分/名”的关系是……如果没有关系，也要说明它更接近用人、刑赏、财赋或兵法判断。操作化建议：不要强行套框架，能贴上才贴。
```

### 历史验收

- 卷次、年份、人物、数字已核原文。
- 每个核心事件有原文锚点。
- 解释了司马光的编排，而不是只讲现代历史知识。
- 关键事件有旁证或至少列出待核方向。
- 只做事件骨架时不得标“已精读”。

## 2. 电工实操式格式

适用：电工教材、维修手册、设备说明书、故障排查记录、电路图解释、安全规程。

### 最小合格单元

```markdown
### 材料段 N：操作/原理/故障主题

> 原文/手册/题目/故障描述照录。若来自现场图片或表格，先转写关键文字和参数。

这段先要确认的是安全边界。涉及带电、断电、测量、拆接线、配电柜、变频器、电机、PLC 输入输出时，必须先说明是否需要断电、上锁挂牌、验电、放电、个人防护和禁止动作。没有安全边界的电工精读不合格。操作化建议：动手前先写“这一步允许带电吗”。

这段讲的实际对象是……这里把设备、端子、回路、负载、保护元件、测量点和信号路径说清楚。不要只讲概念，要让读者知道手该摸哪里、表笔该放哪里、不能碰哪里。操作化建议：把原文里的每个设备名对应到现场位置或图纸符号。

这一步为什么这样做……这里解释电气原理、测量逻辑和判断条件。例如测电压是在判断供电是否到位，测压降是在判断接触电阻或线路损耗，测通断是在断电状态下确认回路连续性。操作化建议：每做一个测量，都先写下“这个读数要排除什么故障”。

如果读数/现象不同，下一步应该怎么分叉……电工实操精读必须给出判断树，而不是一句“检查线路”。比如有电压无动作，看线圈/负载/控制信号；无电压，看上级保护、端子、开关、互锁。操作化建议：读完这段，要能画出至少两个分支。

常见误操作是……这里要写具体风险，如未验电就测电阻、带负载拔插端子、把零线和地线混用、只看空载电压不看压降、换件前不确认故障源。操作化建议：每个步骤后写一个“不要做”。
```

### 电工验收

- 安全优先，必要时先写 LOTO/验电/放电/PPE。
- 解释必须落到设备、端子、回路、读数和动作。
- 有测量目的和分支判断，不只讲原理。
- 易错点必须独立标出。
- 不确定现场条件时，明确说明不能指导实操，只能做原理性分析。

## 3. 哲学方面格式

适用：哲学原著、理论文本、概念密集段落、思想史论述。哲学格式尤其禁止用直觉类比绕过概念。

**v2.7.0 补充硬约束**（依据用户 2026-09-12 反馈）：哲学 close reading 的每个"节点 / 概念展开"必须严格按以下范式写：

1. **核心命题**（一句话直接陈述，不绕弯）——例如：“谢林这里的时间是先验时间（transzendentale Zeit），即构造经验时间的形式本身。”
2. **概念 A 是什么**（定义、词源、机制、如何运作）——必须真正展开，不能用“暗示”“意味着”“暗指”这类元叙述词勾连。
3. **概念 B 是什么**（定义、词源、机制、如何运作）——同上。
4. **A 与 B 的关系**（差异、承继、对比、限定）——只在 A、B 各自都展开后才能写。

**错误示例**（反例）：❌“前进暗示有方向”“作为对康德先验哲学的关键改造”“这是对费希特的核心反驳”——这些都是用元叙述词把概念勾连，但概念本身未展开。

**正确示例**：✅“谢林这里的时间是先验时间。先验时间相对于经验时间：经验时间是日常感受到的线性流逝，先验时间是构造经验时间的先天形式条件。康德在《纯粹理性批判》先验感性论中明确论证：时间是内感官的形式。谢林的改造是把先验逻辑从静态形式推进为先验发生学（transzendentale Genese），处理动态的过程。”——每一句都是直接陈述 + 概念展开，无元叙述勾连。

更多反例与正例详见 `agent-role.md §7.7 解读范式`。

### 最小合格单元

```markdown
### 原文段 N：概念/论证主题

> 原文照录。外文文本保留原文，必要时附译文；译文有争议时标明版本。
> 选段粒度以“论证单元”为准（一个完整的问题—前提—结论结构），而非自然段；论证单元过长时进一步节选并注明范围，保证解读篇幅 ≥ 原文 5 倍的比例底线。
> 中译底本精读时，“原文在场”= 中译全文照录 + 关键术语保留原文 + 交代版本信息（译者、底本、页码/编号体系）；不要求外文全文照录，也不允许完全不保留外文术语。

这段真正提出的问题是……哲学精读不能先给鸡汤式结论，而要确定作者在回应什么问题。这里要说清楚问题的形式：定义问题、根据问题、条件问题、反驳问题，还是概念区分问题。操作化建议：先把本段改写成一个问题句。

**对象是论战性文本（polemical text）时——作者以回应外部已有攻击开场，而非发起新论证——须先做论战识别与对手主张分层，再进入常规解读。** 识别特征：开场句是"按照一个古老的说法""人们据说认为""某派主张"等转述＋紧接反驳，或第一论证单元的直接任务是否定某个已发表的立场（如谢林《自由论文》开篇回应雅各比"自由与体系不共戴天"，齐泽克前言回应"精神分析是托勒密化"）。此时"作者在回应什么问题"先于"作者说了什么"：把论战开场读成体系开幕，会把防御性限定句误读成正面主张。论战拆解三步：① 先写出对手是谁、对手主张的原文表述、作者引用的目的（直接引用/树靶/承认其部分真）；② 把对手主张按"层面"拆分处置——语义层（语词含义导致的自我证真，如"体系"的褊狭含义让断言自证为真但等于没说）、原则层（概念关系，如"自由概念与体系概念本身不共戴天"）、认知可能层（如"体系绝不可能达到人类知性"）——各层面处置动作不同（承认但不予置评/正面反驳/悬置），并区分"强度升级"（同一命题越说越强）与"战线转移"（换到不同层面），二者不是一回事；③ 追踪作者是否更换战场——把辩论从对手设定的框架移到自己的框架（如从"体系能不能与自由共存"移到"用什么本原把自由与体系统一起来"），更换框架是论战文本的收束动作，位置往往在"关键在于……"处。**限定句的层级身份**：作者论战中"很难反驳/诚然/固然/不可否认/姑且承认"等限定句不是认同标记，是"缩小对手主张效力范围"的第一步；作者立场通常在限定句链的终点，不必然有显式对立句（"对立句/赌注句"规则适用于齐泽克式显式转述，谢林/黑格尔式论战靠逐层限定滑入立场，两套识别法都要会）。操作化建议：给论战段每句标层级身份标签——转述对手/承认限定/原则反驳/悬置/正面任务——标签标完，误读自动显形。**节选外引用边界**：节选精读可提及节选外紧邻的论证动作作为上下文（功能补述，如"原单元后半批判了费希特"），但不得把节选外原文当已照录内容展开精读，也不得以节选外内容替代本段照录。

这段的概念用法是……关键词首次出现必须给出本段语境中的定义，而不是百科式定义。若有原文术语，要说明译法、词源或语义张力；但溯源只能服务于这段，不能炫耀学术史。操作化建议：每个术语后面写“在这里它指的是……”。

作者的论证链是……这里重建前提、推理和结论。哲学文本最怕只翻译不解释，必须把隐含前提说出来，把转折处的必要性讲出来。操作化建议：把本段写成"前提1—前提2—因此"的形式，再看是否成立。

重建论证前先区分"转述他人立场"与"作者自己断言"：识别"声称/据说/学界认为/某学科的基本前提是"等引述句式，引述句后面的内容往往是对方判词而非作者主张；作者真实立场通常在转述句之后的对立句或赌注句里（如齐泽克"认知科学的基本前提是，精神分析是托勒密化"是转述判词，立场在全书赌注里）。不得把转述当作者主张，也不得把作者赌注当转述。操作化建议：给每个关键断言打标——定义/例证/转述/赌注，四类读法不同。

哲学文本的例证分四类，必须按功能处理，不得一刀切：**定义装置**（概念靠它立义，不可替换，删掉论证即塌）、**应用演示**（展示概念适用范围）、**挑衅性套用**（逼读者接受极端推论，往往是作者真正锋芒所在，如把马克思批判也说成托勒密化）、**修辞性类比**（可替换的"打个比方"，删之无损）。判断标尺是"可替换性：删掉它论证塌不塌"；承重例证（前两类）必须展开分析，修辞例证不得当论证读。"禁直觉类比"防的是用修辞类比替代概念推理，不是禁止分析承重例证。跨学科借入的概念（托勒密化、拓扑、熵、能指）须标注隐喻边界：在此承担结构功能，不承担原学科全部含义（如"托勒密化"取补丁式应对之结构，不承担天文学史真实性），既不得拿原学科考据怼概念，也不得把隐喻当严格概念。

这段在全书中的位置是……它承接前面哪个概念困难，又为后面哪个论证铺路。哲学不是孤立金句，概念只有在论证运动里才有意义。当文本处于作者思想转型期（如谢林 1809–1815、康德批判时期），可对照同一作者早/晚期文本中同一概念结构的位移（如“双重本原”从《论人类自由的本质》的上帝之内转到《世界时代》的人之内）——同一结构的位移往往就是思想转向的坐标；此为作者自身文本的对照，属本领域内部工具，不属于外部学术史装饰，但需标注“与作者 X 文本的对照”。操作化建议：读完本段，写一句“它让后文能够讨论……”。

最容易读错的是……这里指出常见误解，例如把规范性命题读成心理描述，把存在论判断读成经验事实，把概念区分读成价值高低。操作化建议：先排除一个错误读法，再保留正确读法。
```

### 哲学验收

- 原文与译文版本清楚。
- 概念定义贴着本段语境，不做概念百科。
- 论证链可复述。
- 不用类比替代概念推理。
- 必须说明本段在前后论证中的功能。

### 3.1 概念定义贴语境五动作（哲学 close reading 必备动作清单）

> 适用：所有哲学文本（不论中译本/外文原本/导读笔记型）。第 22 轮拉康《康德同萨德》§（一）段测试沉淀——本段涉及 7 个首次出现术语，每个术语在 §（一）原文中的出现都承担特定论证功能，不是百科词条。哲学 close reading 不能只翻译术语，必须把术语锚在本段论证里。

哲学 close reading 在每个首次出现的术语处做下列五动作：

- **(a) 标出术语首次出现位置**——段内位置（句首/句中/句末）+ 段间位置（开篇/中段/结尾）；位置本身承担论证功能，开篇术语 = 作者框架声明，句中术语 = 论辩展开，句末术语 = 收束断言。
- **(b) 从句内主谓宾关系推术语定义**——不查百科，不依赖既有哲学史记忆，只从该句的主语、谓语、宾语、补语推断术语在作者这里指什么；推出来的"语境定义"是后续一切判断的基线。
- **(c) 标出术语在本句承担什么论证功能**——定义功能（首次给出概念）/ 对比功能（与已给概念并列/对立）/ 嫁接功能（与已熟悉概念挂钩）/ 反讽功能（用术语嘲讽某派）；同一术语在不同句可承担不同功能。
- **(d) 把术语的"语境定义"与"标准定义"对照**——标准定义来自教科书/哲学史/通行翻译；语境定义可能与标准定义有出入——这是精读关键，因哲学论证往往借助"偷换定义"推进；差异点必须标出，但不必立刻评判作者对错。
- **(e) 标出该术语在后文是否再次出现**——首次出现 vs 多次出现的处理策略不同：首次出现要花力气在 (a)(b)(c)；多次出现要追踪"定义漂移"——每次出现语境定义是否一致，不一致时是作者推进论证还是论证不严。

- **(f) 语境边界声明（2026-08-26 轮次 26 沉淀）**——长篇著作的术语跨段/跨篇承担不同语义时，必须做边界声明，避免简单合并：
  - (f.1) 标出该术语在本段/本篇承担的语义——精读本段时按本段语义用，不外推。
  - (f.2) 标出该术语在同书其他篇是否承担不同语义——若有，需说明差异（如刘勰"立言"在《序志》承担"著作传后世"，在《诸子》承担"炳曜垂文"，虽都属"立言"但具体语义不同）。
  - (f.3) 跨段/跨篇归纳时不能简单合并——需标注"本段特指 X，跨段综合时仍要回到各段原意"。
  - **典型场景**：古文长篇著作（《文心雕龙》50 篇、《史记》130 篇、《汉书》全 100 卷）跨篇承担不同语义是常态，**不标边界就合并会导致精读失真**。

操作化建议：每个首次出现的术语花 5-8 行做这五动作，比查百科做名词解释更慢，但能让读者看到术语在论证里的承重位置。

### 3.2 开篇姿态六分类（哲学 close reading 的导航动作）

> 适用：所有哲学文本。第 22 轮拉康《康德同萨德》§（一）测试沉淀——拉康开篇是"反俗论+立新论"，与维特根斯坦/康德/海德格尔等开篇姿态完全不同。哲学文本的开篇姿态决定后续如何读：正面立论的文本可顺序跟读，反俗论文本要先识别"作者扫掉的俗论是什么"。

哲学文本的开篇姿态至少有六类：

- **(i) 正面立论**——开篇即给出核心命题（如维特根斯坦《逻辑哲学论》"世界是事态的总和"）。读者只需顺序跟读论证链。
- **(ii) 反俗论**——开篇先扫掉一个流行解释，再立自己的解释（如拉康《康德同萨德》"说萨德的著作预期了弗洛伊德，这是在文学批评中讲烂了的一句蠢话"）。读者必须先识别作者扫掉的俗论是什么，再看作者立的新解释。
- **(iii) 反他人**——开篇直接回应某派/某人的具体主张（如谢林《论人类自由的本质》回应雅各比"自由与体系不共戴天"）。读者必须先读懂对手主张是什么，再读作者的反驳——这是论战型文本，漏读对手会让作者反驳悬空。
- **(iv) 引他人**——开篇借引某经典/某权威建立地基（如海德格尔《存在与时间》引亚里士多德"此在"展开）。读者必须核验引用的准确性与作者解读是否一致。
- **(v) 命题清单**——开篇直接列一组命题/定义，读者跟读每一项的论证（如斯宾诺莎《伦理学》"定义一/定义二/...")。读者要把命题清单当作"作者的世界观地图"读。
- **(vi) 悖论式开篇**——开篇给出看似自相矛盾的命题（如黑格尔"凡是合乎理性的都是现实的，凡是现实的都是合乎理性的"）。读者要识别这是修辞而非错误，作者用悖论逼读者修正既有概念。

操作化建议：读哲学论文/著作开篇前两段，先问"作者用了哪一类开篇姿态"——这一动作完成后，读者对后续论证的预期就已锚定。

### 3.3 骨架节 vs 血肉节预判（避免精读工作量浪费）

> 适用：哲学论文/章节。第 22 轮拉康《康德同萨德》§（一）（骨架节）与 §（二）（血肉节）测试沉淀。哲学文本有"骨架"与"血肉"两类不同章节：骨架节必须精读每个论证节点；血肉节可以略读作者的应用细节。一律精读会浪费时间，一律略读会漏掉论证节点。

判断标准：

- **骨架节**——满足下述任一条件：(1) 开篇章节（含序言、导论、第一节）；(2) 提出核心命题；(3) 给出论证骨架（前提-推理-结论结构）；(4) 引出新概念或新论证模式。
- **血肉节**——满足下述任一条件：(1) 中段章节（应用核心命题于具体案例）；(2) 给出具体应用/例证/反例；(3) 回应他人对骨架节的批评；(4) 注释/附录/译后记。

预判动作——读章节标题 + 前两段就能判断本节是骨架还是血肉：

- 是骨架节 → 必须做全部五动作（语境定义/论证链/防误读/位置功能/操作化建议）。
- 是血肉节 → 选 2-3 个关键论证节点精读，其余略读+标注"血肉节详读建议"即可。

操作化建议：拿到一本哲学书/一篇哲学论文，先看目录，把骨架章节标红、血肉章节标灰——只对标红章节做完整精读，标灰章节做扫读式精读。

### 3.4 导读笔记型二手文本（哲学变体）

适用：raw/哲学/ 下常见的一类特殊文本——读者的"中英对照+个人化白话解读"型导读笔记（典型如 BORIS ZHU《小逻辑 1-83》PDF：黑格尔英译段 + 某中文读者白话导读 + 个人网络/跨学科嫁接）。这类文本不是哲学原著（如齐泽克、谢林那样作者本位的原创文本），也不是已有中译本的衍生品（如贺麟中译本）——它是一种**"原文"身份模糊**的二手文本：底本同时承载"最内层作者原文"（黑格尔/谢林/海德格尔等古典哲学家）与"导读者的现代汉语重写"，且二者混排在同一页面上。

哲学格式 §3 的原文层、译文层、解读层在此必须分列：底本最内层作者原文 = "原文"，导读作者的中文段 = "导读"（不是"中译"，因不与通行中译本同步），二者**分列照录**，不当同一层处理。

#### 精读姿态

- **三层标签**：每段贴层标签——"原文（内层作者）/ 解读（导读者的白话）/ 嫁接（跨学科或网络隐喻）"；标签贴完，导读者在哪一层是忠实传达、哪一层是个人发挥才看得清。
- **传达忠实度评估四问**（不是逐字翻译校对，是概念层有效性的评估）：
  - (a) 关键术语是否漏译/合并（如"perception"被"感信普"三分砍掉，丢失了认知阶梯）。
  - (b) 语气/反话是否被加重或去除（如"seems"被译为"压根儿"，去掉反话——可能让读者以为作者在断言而非反讽）。
  - (c) 隐喻/修辞是否被跨时代替换（如黑格尔"forget meanwhile"被替换为"爆杀"网络修辞——风格跨时代是允许的，但会让读者误以为作者在用网络战修辞）。
  - (d) 跨学科概念是否被嫁接（拉康"小写对象 a"、齐泽克"主体"等借入——按 §3 已沉淀的"隐喻边界"规则，标注"在此承担结构功能，不承担原学科全部含义"）。
- **导读者位置声明**：把导读者的自序/前言作为"导读者的对话位置"读（自承幼稚 vs 自命权威影响"忠实度"姿态评估），不当正文也不当噪声过滤。
- **忠实度的边界声明**：忠实度不等于"逐字翻译"，等于"概念层传达的有效性"；"导读者的有效发挥"是合理贡献（戏剧化、跨学科嫁接可帮助读者理解），"导读者的过度发挥"（引入原文没有的判断、把加重语气当作者原意）是问题；执行者须区分。

#### 比例计算基准

- 以"底本最内层作者原文"为分母（即黑格尔/谢林等古典哲学家的原始段），不以底本呈现给读者的全部文字算；这样比例底线（≥5 倍）与"中译底本"统一。
- 例：导读笔记一段含"黑格尔英译 360 字 + 笔记作者中文导读 540 字"共 900 字，精读 3000 字——若按全部 900 字算约 1:3.3（压线），按黑格尔英译 360 字算约 1:8.3（达 1:5-1:10 底线）；按"最内层原文"算比例更接近"中译底本"的执行规则。

#### 验收

- 原文在场（底本最内层作者原文，与导读者段分列）。
- 导读者解读段在文中明确标注"导读者发挥/跨学科嫁接"，不冒充原作者立场。
- 跨学科嫁接处按 §3 沉淀的"隐喻边界"规则标注。

### 3.4.b 导读笔记型的解读姿态边界（2026-08-26 轮次 26 沉淀）

> 适用：所有导读笔记型底本（导读笔记 / 学习辅导 / 教材 / 参考书 / 学者精读集——典型如杨明《文心雕龙精读》、周振甫《文心雕龙今译》、王元化《文心雕龙创作论》、朱自清《诗言志辨》等）。**导读笔记型底本是 deep-reading 处理的常见类型**（raw/古文/、raw/哲学/、raw/计算机/ 下皆有），但其解读姿态有清晰的长项与短项——与哲学 / 历史 / 古文格式叠加时的分工必须明确。

按解读姿态拆分，导读笔记型的长项与短项如下：

- **(a) 导读笔记型的长项（情感化还原 / 共情式描述 / 文本信号 → 情感推断）**：
  - 情感化还原——把作者的精神处境用情感化语言还原给读者（典型如杨明"这实在使人同情"+"矛盾的心情"）。
  - 共情式描述——以读者共情为目标的写作（用第一人称、第二人称、情感化措辞建立读者与作者的情感通道）。
  - 文本信号 → 情感推断——从具体文本信号（叠字节奏 / 关键语气词 / 修辞夸张 / 情感收束）推断作者情感状态。
  - **这些动作在导读笔记型中是标准姿态——读者购买的就是这个；不要因为它不像学术论文就批评它**。
- **(b) 导读笔记型的短项（结构化拆解 / 反向论识别 / 跨文本互证）**：
  - 结构化拆解——把作者的情感描述还原为结构（如"开篇高呼 + 结尾低叹"的反差结构、"立言主张 + 知音难逢"的并存结构）。
  - 反向论识别——识别作者话语中"看似自相矛盾实则结构性反向论"的深层智术（如刘勰"立言主张 vs 知音难逢"是反向论而非自相矛盾）。
  - 跨文本互证——把本段放到作者其他文本、传统谱系、其他作者文本中做对照（如把刘勰"立言"放到曹丕"立言" → 陆机"立言" → 刘勰"立言"传统中看位移）。
  - **这些动作在导读笔记型中通常不出现——导读姿态擅长还原情感，不擅长拆解结构**。
- **(c) 与哲学 / 历史 / 古文格式叠加时的分工**：
  - 导读笔记型做情感化长项（还原作者处境 / 推断情感 / 建立共情通道）。
  - 哲学 / 历史 / 古文格式做结构化短项（拆解结构 / 识别反向论 / 跨文本互证）。
  - **两者叠加读 = 完整的文本理解**——只用导读笔记型会停在情感层，只用哲学 / 历史 / 古文格式会停在结构层，缺一不可。
- **失败模式**：
  - 用哲学 / 历史 / 古文格式批评导读笔记型"不够学术"——错位，导读笔记型的本职是情感化还原，不是结构化拆解。
  - 用导读笔记型覆盖哲学 / 历史 / 古文格式的精读——错位，情感化还原不能替代结构化拆解。
  - 混用两层（既做情感化还原又做结构化拆解，但不做"长项/短项"分工）——结果两层都不到位，读者读完既不感动也不理解。
- 比例计算以"底本最内层作者原文"为分母。
- 导读者自序/前言作为"位置声明"读，不混入原文段。

## 3.5 小说/叙事文学格式

适用：小说、网文、类型文学、叙事散文、剧本/故事文本。叙事文本的任务不是"论述"而是"让人物行动、让读者追问"——精读的维度与说明文完全不同。

### 精读姿态（先读这一条）

- 类型文本（网文、推理、言情、武侠等）先识别类型惯例，再读文本对惯例的运用与变异：网文的"黄金三章"（开篇立人设/立悬念/立矛盾）、"金手指"（主角核心能力）、"道心"（主角意志宣言）是类型读者的共同预期，识别它们才能读出门道。
- 文笔判断放回类型语境：网文里"嫣然"形容将死的男魔头是刻意的错位设计（死亡奇观），不是用词失误；纯文学标准与类型惯例冲突时，先问"作者用这个写法在类型里完成什么功能"。
- 防止两个极端：不用纯文学审美苛责类型文笔（把惯例当缺陷）；也不只做套路/爽点拆解而不做文本细读（"这就是扮猪吃虎"不是精读）。

### 最小合格单元

```markdown
### 原文段 N：场景/节拍主题

> 原文照录。选段以"场景单元"为单位（一个完整的地点-时间-人物行动块），单场景超过 500 字时节选关键节拍并注明范围；原文照录后，精读段落群按叙事维度展开。

这段的叙事位置与功能是……这个场景在全书/本章结构中承担什么任务：立人设、立矛盾、埋钩子、信息释放、节奏缓冲？场景切换（尤其无过渡硬切）处悬着什么线？操作化建议：读完先标"这个场景完成了什么叙事任务"。

这段的对话在做什么……对话按功能分组：交代信息/塑造人物/制造张力；标出"谁在说、对谁说、说话时局面如何"；无人称众声（群体宣言）与点名对话的功能差异。操作化建议：同一场景的对话按功能分组，不要只记台词内容。

这段的人物塑造手法是……神态/动作/心理/他人反应四条通道，作者用了哪条？"配角反应是主角强度的度量衡"；错位词（形容词与人物身份不符）处往往是作者刻意加的分。操作化建议：找"作者用谁的视角确认人物强度"，再找错位词。

这段的意志宣言/金句是……主角在重大时刻对生存方式的确认（网文"道心"），它与开篇/本章场景的关系；引典处核出处（如化用古典诗词），并读"引用义与原文义的分合"。操作化建议：先找宣言，再核它用什么代价立的、后文是否兑现。

这段的节奏控制是……动词压在哪里、状态描写占多大比重、高潮前如何积累（静极而动）；信息补给（闪回/背景）插在情绪顶点的哪一侧。操作化建议：把动作句与状态句分别标色，看动词被压到何时出现。
```

### 小说验收

- 原文在场（选段注明场景单元边界，节选注明范围）。
- 叙事维度覆盖（结构/对话/人物/宣言/节奏至少四项），不做句意层转述。
- 类型惯例已识别（适用时），文笔判断放回类型语境。
- 文本内自洽核验：时间线、数字、人物设定前后一致（如"三百年+两百余年=五百余年"）。
- 引典/版本核验：化用或引用古典诗词处核出处；底本（整理本/修订版 vs 原版）差异注明。
- 操作化建议从叙事语境长出，不写泛写作学套话。

## 3.6 批判性/立场性文本格式

> 第19轮（2026-08-25，底本《白色女权报告》）沉淀。前 18 轮所有底本都不在"带立场写作"光谱上，这一格式应需求而生。

适用：政治批判报告、媒介批评、社论、自媒体观点文、政党/智库文件、组织自我宣传稿、立场性研究综述、价值判断密集的杂文。

不适用：纯技术教材（通用型）、学术综述（有自然让步论证）、编年体历史（历史风格）、纯哲学论证（哲学格式）。判别准则：底本是否**第一句话就给出价值定性断言**，且**核心判断词未经定义直接承担论证**。

### 最小合格单元

```markdown
### 原文段 N：立论主张 / 论证节点主题

> 原文照录。批判性文本常以"立论定调段 + 具体节点段"展开，选段优选立论定调段；具体人物指名段宜选段回避（见本节末尾 "### 选段姿态"）。

这段的论证骨架是……这里不评判立场对错，而是把作者做了什么断言、用了什么前提、给了什么证据分开列。带立场文本的精读姿态是"展示论证而不是评判立场"——读者读到的是结构，不是判断。操作化建议：读带立场报告时，主动用"他主张了什么 / 他怎么论证的 / 他跳过了什么"三栏笔记法，不写"他错了 / 他对了"。

这段的核心概念（负担词 / loaded term）是否被定义……核心论证词若在首次出现时未给出操作性定义，等于论证起点未澄清——它能在后文承担所有负面归类。需列出"未定义就承担论证"的具体词。操作化建议：每读一篇带立场文本，找三件事——核心概念首次出现位置 / 归类标准 / 反方定义；三件都没回答时，整篇论证建立在负担词上。

这段的修辞策略是……评价性词（"危害巨大""温床""蓄意"）与中性叙事词（人名、机构、活动名）按强度分级列出；暴露句式（"打着 X 旗号 / 实质上却是 Y"）需要特别标出——它是引导读者"站到作者视角看"的修辞装置，不是中性描述。操作化建议：把每句话的"表面词 + 暴露词"分开看，删掉暴露词句子不成立时说明修辞承担论证而不是证据承担论证，要警惕。

这段的分类框架是……二元对立结构（境外/境内、自由主义/民粹、线上/线下、表/里）容易带值——分类标准未声明 / 分类带值但被当中性呈现 / 第三类缺席，这三类问题统一列出。读者读完看到的不只是"作者批评了什么"，更是"作者怎么让读者接受自己的批评"。操作化建议：每读带立场报告的二元分类，把每个词单独拎出来问"作者凭什么归到这一类 / 为什么不归到另一类 / 有没有第三类可能"。

这段的反证缺口是……让步论证（"虽然有人认为 X，但本文基于 Y 主张 Z"）是否出现。批判性立场可以不需要让步——战斗性立场天然就是立场鲜明的——但让步缺席提示读者：把作者判断当成"主张"而非"经过反驳检验的判断"。操作化建议：不写让步不等于论证错误，但读者应意识到"作者没与反方对话"和"作者经反方检验过"是两种不同的判断接受度。

这段的操作化建议是——读这类带立场文本的五步工具：(1) 拆开三层断言；(2) 分开评价性词与中性词；(3) 找核心概念是否被定义；(4) 检查二元分类带值与第三类缺席；(5) 检查反证缺口。五步动作只用于读带立场报告，不用于读科学论文/技术教程/编年体史料等中性文本。
```

### 选段姿态

读批判性/带立场文本时，选段有"边界保护"约束：

- **优选立论定调段**（开篇第一章第一节、框架声明段、核心判断段）。理由：立论定调段是全篇论证骨架的微缩标本，能独立成段完成最小合格单位。
- **避开具体人物指名段**（实名/网名指认、私人细节段、丑闻段落）。理由：精读会引来"评价具体人物"风险，巡检员应避免。这一回避不等于内容回避——选"提到人名但只用于分析论证结构"的中间态是合理的。
- **避开敏感机构点名段**（境外注册 NGO、境外媒体、政治反对派机构段）。理由同人物段。
- **建议避开跨多章的总结段**——批判性报告常以"总而言之""综上所述"等收束段做总结，但总结段不构成新的论证，只重复既有判断。

### 3.7 反向论识别三动作（哲学 close reading 必备动作）

> 适用：所有哲学文本。第 22 轮拉康《康德同萨德》§（一）"《卧房》给出了《批判》的真理"段测试沉淀——把出版时间晚的萨德作为出版时间早的康德的"真理"，颠倒历史时间顺序。这种"反向论"在哲学论文中常见（黑格尔《精神现象学》序言把哲学史改写为"理念自我实现史"，尼采《道德的谱系》把"善"颠倒为"恶"，海德格尔把西方形而上学史改写为"存在的遗忘史"）。

哲学 close reading 碰到反向论必须做三动作：

- **(a) 标出"反向论"标志词**——典型句式包括："X 给出 Y 的真理"、"X 才是 Y 的本质"、"Y 不依赖于 X 而 X 依赖于 Y"、"X 是被 Y 颠倒过来的"、"看起来是 X，实则是 Y"；标志词出现即触发反向论识别。
- **(b) 解释反向论颠倒的是什么常识**——反向论必然颠倒某个被广泛接受的常识/历史叙事/直觉判断；不指明被颠倒的常识，反向论本身不可理解。如拉康"《卧房》给出《批判》的真理"颠倒的是"哲学影响文学/思想影响作品"的常识。
- **(c) 评估反向论是否带来新的论证**——反向论有两种：一种是**修辞性反向论**（只为强调新解读，不改变论证结构）；另一种是**结构性反向论**（颠倒常识本身就是论证关键节点）。判断标尺：删掉反向论后论证是否仍成立——成立是修辞性，不成立是结构性。结构性反向论必须展开分析。

操作化建议：读到任何"X 才/才是/才是 Y 的本质/真理"句式，立刻做 (a)(b)(c) 三动作；否则容易把作者的反讽/修辞当正面主张读。

### 3.7.b 自序/序志类文本的反向论高频场景标记（2026-08-26 轮次 26 沉淀）

> 适用：所有自序 / 序志 / 赠序 / 悼文 / 书信 / 私志类文本。**这类文本是古文精读的最重要底本**（《史记·太史公自序》《汉书·叙传》《文选》序、《文心雕龙·序志》、韩愈《送董邵南序》、柳宗元《答韦中立论师道书》、曹丕《典论·论文》、嵇康《与山巨源绝交书》、陶渊明《五柳先生传》等），反向论在自序类文本中以特定模式高频出现，必须独立标记。

自序 / 序志类文本中反向论的高频模式与判别：

- **(a) 高频场景判别**：
  - **私人情感类文本**：自序 / 序志 / 赠序 / 悼文 / 书信 / 私志——这些文本承载作者的私人情感、精神处境、人生期待。
  - **作者精神处境复杂**：作者往往是"立德 / 立功 / 立言"中"立言者"（不是直接立功者），精神处境往往是"立德 / 立功 / 立言"三层中的"次优解"或"补偿解"。
  - **面对读者群明确**：自序面向后世读者（"千年之后偶一遇之"），不是当代知音——这种"读者已不在场"的设定让反向论高频出现。
- **(b) 反向论的高频模式（开篇 vs 结尾的方向反转）**：
  - **开篇高呼 vs 结尾低叹**：开篇定基调（"立言不朽"的合法性主张 / "为天地立心"的宏大叙事），结尾显真性情（"千载其一"的最低期待 / "知音难逢"的孤独感）。两句并读才是真实处境。
  - **立德 / 立功 / 立言三层中选择最弱者**——自序类作者往往是"立言"者（不能立德 / 不能立功），反向论常表现为"反向抬高立言"或"反向贬低立德 / 立功"。
  - **天命话语的反向挪用**——借佛教三世之说（往代 / 来世）或道家齐物之言，把"立言不朽"重新定义为"跨代不朽"（而非同时代不朽），完成身份转换。
- **(c) 失败模式**：
  - 把反向论当"抱怨 / 自嘲 / 无病呻吟"读——错失作者的精神自救技术。
  - 只读开篇或只读结尾——失真，必须开篇与结尾并读。
  - 不识别"立言 / 立德 / 立功"三层期待差异——把"立言"当最高追求读（错失立言是次优解的实质）。
- **(d) 与 §3.7 的关系**：§3.7 是反向论的通用三动作（标标志词 / 解释颠倒什么 / 评估是否带来新论证）；§3.7.b 是反向论在自序 / 序志类文本的特化形态（开篇 vs 结尾 / 立言者身份 / 跨代不朽）。**两者叠加使用**：先用 §3.7 通用三动作识别反向论，再按 §3.7.b 检查是否符自序类文本高频模式。

操作化建议：读到自序 / 序志 / 赠序 / 悼文 / 书信类文本，先问三个问题：(a) 作者是"立德 / 立功 / 立言"哪一层？(b) 开篇与结尾方向是否反转？(c) 反向论是修辞性（仅为强调）还是结构性（删掉后论证失去基础）？——这三问比逐句训诂更快速定位作者真实处境。

### 3.8 延伸解读边界声明（严格版，哲学 close reading 必填）

> 适用：哲学 close reading 区别于历史 close reading 的关键：哲学论证"一词之差就是新命题"（如"颠覆的第一步"vs"颠覆的全部"是不同命题），所以延伸解读边界必须比历史更严格。第 22 轮拉康《康德同萨德》§（一）测试沉淀——本段涉及 4 项延伸解读，每项都标注"原文能支撑到什么、不能直接支撑到什么"。

哲学 close reading 的延伸解读必须包含下列三栏：

- **第一栏：延伸断言**——明确写出"延伸解读说 X"。
- **第二栏：原文支撑度**——明示"原文能直接支撑到什么"（必须引原文具体句子），以及"不能直接支撑到什么"（必须说明原文缺口在哪）。
- **第三栏：互证强度**——给出"互证强度标签"（强互证 / 弱互证 / 单例未互证 / 哲学论证型未互证）。哲学延伸解读往往是与作者其他文本的对照（如谢林早期《论人类自由的本质》vs 后期《世界时代》的"双重本原"位移），这种对照属于作者自身文本互证，强度比单一卷次内单例高。

哲学延伸解读的特别要求：**哲学论证中一词之差就是新命题**，所以延伸解读的边界声明必须比历史 close reading 更严——历史可以"类比一下试试"，哲学不行；哲学延伸解读若与原文论证结构有冲突，必须明示冲突点，不能用"合理推论"搪塞。

操作化建议：哲学 close reading 的每一项延伸解读都按三栏格式写；缺一栏就不算合格的边界声明。

## 4. 格式选择规则

用户明确说历史、通鉴、史料：用历史格式。

用户明确说电工、维修、接线、故障、设备、测量、图纸：用电工实操式格式。

用户明确说小说、网文、叙事文学、剧本、故事：用 §3.5 小说/叙事文学格式。与通用型的分工：叙事文本不用通用型（通用型服务论述、说明、教材）；传记/纪实文学等半叙事文本，先按主要任务选格式，叙事成分借用 §3.5 的维度。

用户只说"精读这篇/这本/这段"：先用通用型格式；如果读到明显领域特征,再切换对应格式,并在落库中说明采用的格式。软件/编程/数据类技术教材（教程、手册、入门书）默认走通用型，材料核验按扩展六项执行（代码可运行性 + 数字可复算性 + 概念定义一致性等）；不套用电工实操式（硬件/电气向）。

若混合文本出现，例如哲学史、技术史、工程伦理，先按文本主要任务选主格式，再借用其他格式的小节。不要把各种格式机械叠加。

### 4.5.b 古文 + 哲学 + 导读笔记型三层叠加的动作清单（2026-08-26 轮次 26 沉淀）

> 适用：理论性文论底本（如《文心雕龙》《诗经》注疏本、《文心雕龙精读》二手导读等）——同时属于古文（一手原文是文言文）+ 哲学（讨论概念 / 论证）+ 导读笔记型（底本是某学者精读而非原著）三个领域。
> 原本的 §4.5 末尾只指出"理论性文论叠加古文 + 哲学格式要求"，**没有明确三层叠加的具体动作清单**。本轮沉淀补足。

三层叠加的具体动作清单：

- **(a) 双源原文段格式——白话转述只对一手原文做，不对二手导读笔记做**。当一手原文（如刘勰《序志》）与二手导读（如杨明《文心雕龙精读》）同时在场时：
  - 一手原文 = 必须做白话转述（按古文格式的"白话转述"动作）——一手原文是文言文，读者需要白话才能听懂。
  - 二手导读笔记 = 不做白话转述（导读笔记已是白话 / 现代汉语）——再做白话转述是冗余动作。
  - **判别标志**：照录文本是繁体 / 简体文言文 → 一手原文；现代汉语叙述 + 个人解读 → 二手导读笔记。
- **(b) 历代注疏对照应在双源对照中做**。当底本是某学者精读时，必须做"三家注对照"或"两书对读"：
  - 选三家 / 两家以上同等量级注家（如《文心雕龙》选杨明 / 周振甫 / 王元化三家，或拉康导读笔记选 Žižek 原著 / Roudinesco 导读 / 译者注释三家）。
  - 三家对读不只是"谁说得对"，而是"谁在哪个层面说得准"——某些家擅长训诂、某些家擅长哲学展开、某些家擅长历史溯源。
  - **失败模式**：只读一家不读对照 = 接受一家的解读框架作为唯一正解；三家都读但不分工 = 三家同一句话都说成"风格不一致"但看不清谁承担什么功能。
- **(c) 哲学格式的关键动作在叠加场景下的优先级**：
  - 概念定义贴语境（§3.1 五动作 + (f) 语境边界声明）→ 优先级最高，理论性文论的核心是概念。
  - 反向论识别（§3.7 + §3.7.b 自序高频场景）→ 优先级次高，理论性文论常借反向论推进论证。
  - 延伸解读边界声明（§3.8）→ 优先级中，理论性文论往往跨段承担不同语义。
  - 隐喻边界 / 比喻可替换性（§3 已沉淀）→ 优先级中，理论性文论常用比喻。
  - **优先级低的动作**：哲学论证链重建（如黑格尔那种辩证法结构）——理论性文论不是严格哲学论证，不必每段都做论证链重建。
- **(d) 古文格式六块的优先级**：
  - 逐句注释 → 优先级最高，文言文必须做训诂。
  - 深层解读 → 优先级最高，文言文必须做深层解读。
  - 典故与背景 → 优先级高，文言文常用典故。
  - 学者评价 → 优先级中，理论性文论的学者评价可与导读笔记型底本的导读姿态评估合并（参见 §3.4.b 导读笔记型解读姿态边界）。
  - 历代注疏对照 → 优先级中，应在双源对照中做（参见本节 (b)）。
  - 白话转述 → 优先级低（仅对一手原文做，参见本节 (a)）。
- **(e) 导读笔记型层的动作优先级**：
  - 底本判断 + 解读姿态评估（§3.4 + §3.4.b）→ 优先级最高，必须做。
  - 未展开内容点出（杨明没做的 / 周振甫做了的）→ 优先级中。
  - 跨文本互证 → 优先级低，由哲学 / 历史格式承担。

**失败模式（叠加场景下的高发失败模式）**：
- 把古文格式与哲学格式机械叠加，导致精读段落群结构失衡（古文层太长或哲学层太长）。
- 把导读笔记型的解读姿态当原著作者姿态（错把杨明的"使人同情"当刘勰的真实情感）。
- 三层都做但每层都不到位（白话转述省略 / 概念定义简略 / 解读姿态评估草率）。
- 不做三层分工，读者读完不知在哪一层精读发生了作用。

### 4.5.c 骈文对偶即情绪节奏——反向动作（2026-08-26 轮次 26 沉淀）

> 适用：所有骈文 / 对偶文本，尤其是古文（文心雕龙 / 骈体文 / 古文运动前的散文）与哲学文本（黑格尔 / 谢林 / 海德格尔某些段落也用对偶）。
> 原本的 `references/authoring/guwen-template.md` 只有"骈文对偶即分类骨架"一个动作——这是论证骨架场景的标准动作。**但本轮测试发现：骈文对偶在情感段（自序 / 序志 / 赠序 / 悼文 / 书信 / 私志）不承担论证骨架，只承担情绪节奏**。需补一个反向动作。

骈文对偶即情绪节奏的判别与执行：

- **(a) 判别标志（情感段的对偶多为情绪节奏）**：
  - 自序 / 序志 / 赠序 / 悼文 / 书信 / 私志类文本——这些文本承载作者私人情感，对偶多承担情绪节奏。
  - 段内未出现分类词汇（如"四性""八体""六艺""八股"等具体分类数字）——无分类时对偶多承担情绪节奏。
  - 段内有强烈的情感化措辞（"使人同情""矛盾的心情""悲慨""怅然"）——情感氛围主导时对偶多承担情绪节奏。
- **(b) 判别标尺（对偶两翼承担"递进"多承担情绪节奏，承担"并列 + 对照"多承担分类骨架）**：
  - **并列 + 对照型对偶**：多承担分类骨架（两翼分别指两个并列的事物，做对照）——例：《体性》"才 / 气 / 学 / 习"四性并立，《神思》两组对偶即思维四特征骨架。
  - **递进型对偶**：多承担情绪节奏（两翼逐步推进，从"已然" → "或然" / 从"立言" → "知音难逢" / 从"高呼" → "低叹"）——例：《序志》"文果载心，余心有寄"是情感收束；《知音》"知音其难哉，音实难知，知实难逢，逢其知音，千载其一乎"是层层递进的孤独感。
- **(c) 失败模式**：
  - 按"分类骨架"读情感段的对偶，错失情绪节奏的修辞功能——读者会以为刘勰"茫茫往代，眇眇来世"在做"过去与未来"的对照分类，错失这是"时间辽远感的叠字节奏"。
  - 按"情绪节奏"读分类段的对偶，错失分类骨架——读者会以为《体性》"才 / 气 / 学 / 习"在做情感化的修辞，错失这是作家个人因素四性并立的分类骨架。
- **(d) 与"骈文对偶即分类骨架"动作的关系**：
  - 两者并列，先用 (a) 判别标志判断情感段还是论证段，再用 (c) 失败模式判断按哪种动作读。
  - **情感段** → 用"骈文对偶即情绪节奏"——标叠字 / 节奏 / 情感收束；不做分类。
  - **论证段** → 用"骈文对偶即分类骨架"——标两翼关键词 + 分类关系。

操作化建议：读骈文段，先按 (a) 判别标志判断段类型（情感段 / 论证段）；再用 (b) 判别标尺看对偶两翼的逻辑（递进 / 并列对照）；最后按段类型选动作（情绪节奏 / 分类骨架）。本轮刘勰《序志》末段 + 《知音》开篇四组对偶都是递进型，全承担情绪节奏。

## 5. 状态规则

- 只有符合对应格式的“原文/材料段 + 精读段落群”，才能标为精读。
- 只做章节地图、事件摘要、概念列表、操作清单时，标为导读草稿或速读笔记。
- 一次任务范围过大时，主动缩小批次做样张；不得为了进度牺牲精读形态。
