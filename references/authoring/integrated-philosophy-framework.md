# 三套理论整合执行框架

> **本框架的角色**：deep-reading skill 的执行 agent 必须按本框架执行精读任务的"哲学维度"——症候阅读 / 黑格尔-谢林辩证法 / 拉康精神分析三套理论各自是手术刀的某一刃，整合使用才是完整的解剖。
>
> **适用范围**：本框架是**通用的**——适用于任何领域的精读任务（历史文本、哲学经典、文学作品、政治理论、社会学分析、史论专著等）。具体应用案例（§5）以《资治通鉴》为示范，但框架本身不绑定特定文本。
>
> **沉淀依据**：用户 2026-08-31 反馈"目前的分析还是有点浅了"——根因是执行时容易只贴理论标签（"癔症主体""实在界"），不用作手术刀推出新判断。本框架是沉淀产物。

## 0. 立场声明（执行前重读）

**精读不是替作者背书，不是贴理论标签——是用哲学解剖文本。**

- **作者的概念框架是历史材料，不是解释结论**（不替作者背书 / 不把作者的框架当作真理复述）。
- **不带阴谋论**——"阶级统治""遮羞布"等丑恶化措辞改用"位置的必然产物""生存逻辑"。
- **不带道德审判**——人是位置上的承担者，是结构甩出来的附带物（阿尔都塞"无主体的过程"）；剖析是理解位置，不是审判人。
- **不贴标签式批判**——不把作者简化为"阴谋家""权谋家""道德圣人"。
- **不庸俗化**——不写"周天子是糊涂蛋""商鞅是酷吏""张仪是骗子"。用结构性分析代替道德评判。

## 1. 三套理论的分工（不可互相替代）

| 理论 | 读什么 | 关键概念 | 精读中的具体应用 |
|---|---|---|---|
| **症候阅读**（阿尔都塞） | **文本结构**——作者看不见什么 / 沉默处 / 问题域边界 | 双重阅读 / 问题域 / 症候 / 实在界 | 作者为什么写这一段？他没追问什么？被省略的阶级/权力/利益基础是什么？作者问题域的边界在哪里？ |
| **黑格尔-谢林辩证法** | **历史过程**——否定性的运作 / 潜能的逐级展开 | 否定之否定 / 同一哲学 / 潜能阶次 / 历史性 | 旧秩序→新秩序是堕落还是更高阶次的展开？这一卷把过程推到哪个新阶次？历史的反复与退行是什么？ |
| **拉康精神分析** | **主体位置**——人物/作者如何占据位置 / 与大他者的关系 | 三界（RSI）/ 大他者 vs 小他者 / 强迫症-癔症 / 幻想算式 | 这个人物是强迫症还是癔症主体？他面对的大他者是什么状态？作者写人物时自身处于什么主体位置？ |

**关键区分**：三个理论的层次不同——症候阅读处理"作者与文本的关系"，辩证法处理"文本/历史本身的运动"，拉康处理"人物/主体的位置"。它们**不是平行的、不是可互换的**——必须各司其职。

## 2. 整合操作步骤（每个锚点必须走完）

### 步骤 0：精读开始前——显式声明哲学框架

**禁止开始精读而不声明哲学框架**。在锚点写作之前，必须先输出：

```markdown
**本卷复合主轴**：（如 B+C 复合：礼/实撕扯 + 士的去向）
**本卷使用的跨域理论**：
- 症候阅读：（用在哪些锚点，推出什么判断）
- 辩证法：（用在哪些锚点，推出什么判断）
- 拉康精神分析：（用在哪些锚点，推出什么判断）
- 其他：（如唯物史观 / 齐泽克 / 谢林潜能阶次 / 福柯权力分析 / 其他领域理论）
```

这一段是**元叙述的例外**——它不是元指导，而是精读的"工作流标记"，告诉读者本卷的哲学预设。

### 步骤 1：每个核心事件（锚点）必须包含两层以上的理论判断

**核心规则**：
- **至少 60% 的锚点用两套理论**
- **至少 20% 的锚点用三套理论**
- **剩下的 20% 保持显性精读，不强行套理论**

**理由**：三套理论全用会让读者被术语淹没；但只用一套或不用，会变成"作者说什么 + 历史背景"的复述。

### 步骤 2：理论必须是手术刀，不是装饰品

每个锚点内部，理论判断必须从历史事实里"长出来"，而不是**先写一段历史事实、再贴一段理论标签**。

**反例（贴标签）**：
> 张仪欺楚 → 张仪是个骗子（道德判断）
> 楚王被骗 → 因为他贪心（道德判断）

**正例（用理论解剖）**：
> 张仪欺楚的真正机制：楚王**需要**被骗。**他选择相信张仪的六百里地，是因为相信张仪比相信陈轸要舒服得多**——相信张仪，他是"得到六百里地的明君"；相信陈轸，他是"被骗了还不知道止损的昏君"。**被骗者主动加重骗局**——这是癔症主体的典型动作：他不向大他者（中国传统礼的话语）提问"你想要什么"，他直接表演给大他者看（"我是明君"）。

### 步骤 3：拉康精神分析的"主体位置"判断必须有 2-3 个独立证据点

**单点证据只能作为"线索"，不能作为"结论"**。主体位置的诊断需要至少 2-3 个独立证据点（反复出现的同一类动作 / 关键选择 / 公开表演）。

**示例**（以历史人物为例）：
- 智伯的"强迫症主体"判断：①多次戏弄/侮辱他人（蓝台宴戏康子、侮辱段规）②强制索取（索地于韩、魏、赵三家）③被三家反噬后家破人亡。
- 燕王哙的"癔症主体极端形态"判断：①主动表演（让国、收印绶）②通过命名定义自己（"我是尧"）③向已经空壳的大他者提问（"禅让是真礼吗？"）。

**通用化推广**：这一规则适用于任何文本中的人物——文学人物（哈姆雷特、安娜·卡列尼娜）、政治人物（拿破仑、特朗普）、思想史人物（柏拉图、尼采）、哲学论证中的"主体"等。

### 步骤 4：症候阅读必须区分"有意省略"与"结构性盲区"

- **有意省略**：作者知道但选择不写（阴谋论化倾向要警惕）。
- **结构性盲区**：作者在他的问题域之外，所以看不见（这才是症候阅读的核心）。

**判定标准**：作者在同一文本中**反复**回避某类问题 → 结构性盲区（不是阴谋）。

**示例**：
- 司马光反复不写"礼本身的阶级性" → 结构性盲区（他的问题域预设"礼是秩序的根基"，他不会问"礼是否维护特定阶级"）。
- 任何学科的奠基性作者都会反复回避其问题域之外的问题 → 这是结构性盲区的普遍模式。

### 步骤 5：辩证法判断必须落实到"过程阶次"

**不能停留在"作者写了这个"或"这是历史的必然"**——必须落到**这一卷把过程推到了哪个新阶次**。

**适用场景**：
- 历史文本：旧秩序→新秩序的扬弃
- 思想史：旧框架→新框架的扬弃（如亚里士多德→黑格尔→马克思）
- 文学史：旧流派→新流派的扬弃（如古典主义→浪漫主义→现实主义）
- 哲学论证：旧立场→新立场的扬弃

**通用规则**：每次精读都要问"这一卷/这一章/这段文本把过程推到了哪个新阶次"。

## 3. 三套理论各自的"使用模板"

### 3.1 症候阅读使用模板

每个锚点用症候阅读时，必须包含以下要素：

1. **作者档案**：身份、时代、立场、问题域。
2. **作者写了什么**：显性文本判断。
3. **作者没追问什么**：问题的结构性盲区（不是阴谋）。
4. **省略的阶级/权力/利益基础**：经济前提是什么？阶级变动是什么？权力结构是什么？
5. **作者问题域的边界**：他能想到什么 / 想不想到什么。

### 3.2 辩证法使用模板

每个锚点用辩证法时，必须包含以下要素：

1. **正题 / 旧秩序**：这一卷之前的状态是什么？
2. **反题 / 新秩序**：这一卷发生了什么转变？
3. **合题 / 新阶次**：这一卷把过程推到了哪个新阶次？
4. **潜能阶次的展开**：不是"堕落"，而是"同一性的更高阶次展开"——潜能的逐级实现。
5. **过程的反复与退行**：新阶次内部必然有反复（不是线性进步）。

### 3.3 拉康精神分析使用模板

每个锚点用拉康时，必须包含以下要素：

1. **主体核心动作**：该人物最不可理解的动作是什么？
2. **大他者状态**：该人物时代的大他者是谁？稳定 / 不一致 / 不存在？
3. **幻想算式**：$ ◊ a 还是 a ◊ $？
4. **诊断**：强迫症主体 / 癔症主体 / 精神病主体 / 性倒错 / 话术主体（新型）。
5. **证据点**：至少 2-3 个独立证据点支撑。

**通用化推广**：拉康主体位置诊断适用于**任何有"动作-选择-表演"的人物**——历史人物、文学人物、政治家、思想家、哲学论证中的"主体"等。

**拉康"新型主体"识别清单**（不同领域的常见类型）：

| 类型 | 特征 | 历史案例 | 文学案例 | 政治案例 |
|---|---|---|---|---|
| **话术主体** | "实"是话语本身，靠本人能量撑场面 | 张仪型（连横家） | 推销员 / 律师型角色 | 公关型政客 |
| **辩术主体** | "实"是辩术/论证本身 | 公孙龙型（名辩家） | 诡辩家角色 | 智囊型幕僚 |
| **不真信主体** | 能用古典话语消解当下批评 | 陈贾型（用周公故事） | 附和型配角 | 表面中立的外交官 |
| **能调整主体** | 能在不一致的大他者状态下主动调整 | 赵武灵王型 | 觉醒型主角 | 改革型领导人 |
| **命名式主体** | 通过命名/仪式定义自己 | 燕王哙型（禅让） | 通过称号/头衔定义自己的角色 | 通过头衔/仪式重新定义自己 |
| **控制型主体** | 试图控制一切但被反噬 | 智伯型 | 控制狂角色 | 极权型领导人 |

## 4. 失败模式清单（三套理论的共同陷阱）

### 4.1 症候阅读的失败模式

- ❌ **阴谋论化**：把一切省略都说成"故意隐瞒"。**修正**：区分"有意省略"与"结构性盲区"。
- ❌ **否定文本**：症候阅读变成"文本全是谎言"。**修正**：症候阅读不否定显性文本——它把显性文本当作通向深层结构的线索。
- ❌ **脱离原文**：只谈作者的立场，不谈文本本身。**修正**：症候层必须锚定在原文锚点上。
- ❌ **过度拔高**：把每个缺口都说成"实在界"。**修正**："实在界"是强概念，只有结构性、必然性的沉默才配得上。
- ❌ **以今度古**：用现代价值观苛责古代书写者。**修正**：作者不能超出他的时代——症候阅读是理解他的局限，不是审判他。

### 4.2 辩证法的失败模式

- ❌ **机械三段论**：正-否-合的标签代替真正的辩证运动。**修正**：用自然叙述代替标签。
- ❌ **决定论**：以为历史必然走向某个方向。**修正**：潜能是**逐级实现**，不是预定。
- ❌ **进步论**：以为是线性进步。**修正**：黑格尔/谢林都不是线性进步论——过程的展开有反复、有退行。
- ❌ **道德化**：把辩证法当作"历史是公正的最终审判者"。**修正**：辩证法不审判——它解释否定性的运作。

### 4.3 拉康精神分析的失败模式

- ❌ **理论覆盖文本**：把精神分析算式贴到所有动作上，文本消失。**修正**：必须先做历史层，再做精神分析层——文本始终在场。
- ❌ **群体本质化**："中国人是癔症民族"、"古代君主都是强迫症"。**修正**：本框架只用于**具体主体**的解剖，不做群体判断。
- ❌ **拉康即真理**：把拉康的判断当成终极真理。**修正**：拉康是**解释框架之一**，不是唯一真理。
- ❌ **剥离语境**：不顾时代背景直接把现代临床概念贴古人。**修正**：必须把人物放在时代的大他者状态中。
- ❌ **过度解读**：单点证据就下结论。**修正**：至少 2-3 个独立证据点。
- ❌ **回避作者**：用拉康覆盖作者（或其他人物）的判断。**修正**：双向校验——历史层和精神分析层应该互相照明。

### 4.4 整合使用的失败模式

- ❌ **三套全上**：每个锚点都用三套理论，读者被术语淹没。**修正**：每个锚点至少两套，20% 用三套，剩下的 20% 保持显性精读。
- ❌ **理论并列**：把三套理论各写一段，但彼此不互动。**修正**：理论必须互相照明——症候阅读发现的问题，辩证法解释其过程必然性，拉康分析主体位置如何承担这个必然性。
- ❌ **理论与历史/事实脱节**：写一段事实，再贴一段理论。**修正**：理论判断必须从事实里"长出来"。
- ❌ **庸俗化诊断**：写"X 是糊涂蛋" / "Y 是骗子" / "Z 是阴谋家"。**修正**：用结构性主体位置诊断（强迫症 / 癔症 / 话术主体）代替。
- ❌ **绑死特定文本/作者**：把框架锁死在某一本书或某一位作者上。**修正**：框架是通用的——具体应用在 §5 用案例展示。

## 5. 通用应用 + 历史文本案例（以《资治通鉴》为示范）

### 5.1 通用应用规则（适用于任何领域）

- **每卷精读前的"复合主轴声明"**：每卷精读前必须输出（放在章首钩子之后、正文之前）：
  ```markdown
  **本卷复合主轴**：（如 B+C 复合：X 的撕扯 + Y 的去向）
  **本卷使用的跨域理论**：
  - 症候阅读：用在 [锚点 X、锚点 Y]，推出"作者/主体看不见 X"
  - 辩证法：用在 [锚点 Z]，推出"这一卷把过程推到 X 阶次"
  - 拉康精神分析：用在 [锚点 A、锚点 B]，推出"X 是强迫症主体，Y 是癔症主体"
  ```

- **锚点密度的下限**：每卷精读的锚点数量
  - **下限**：5 个核心锚点（少于此数 = 精读深度不足）
  - **上限**：10 个核心锚点（多于此数 = 失去重心）
  - **理想**：6-8 个核心锚点（覆盖主轴 + 旁证 + 转折）

- **锚点的理论配置**（避免单理论锚点占比过高）：
  ```
  理论配置 → 锚点占比建议
  - 三套全用：20%（高密度锚点）
  - 两套组合：60%（如症候 + 拉康 / 辩证 + 症候 / 辩证 + 拉康）
  - 单套理论：0%（避免）
  - 显性精读（不强行套理论）：20%
  ```

### 5.2 通用作者档案模板（适用于任何领域）

> **本节是通用规则**——具体作者档案应作为案例在 §5.2 展示。任何文本精读时，必须先建立对应作者的档案。

每篇精读前必须建立：

1. **身份**：作者是谁、何时出生、何时去世、什么职业
2. **政治/社会/学术立场**：他代表什么群体、他的立场是什么
3. **文本的生产背景**：什么时期写的、为谁写的、目标读者是谁
4. **问题域**：他的提问方式是什么、预设了什么答案
5. **看不见什么**（按领域列举）：
   - 历史文本：礼本身的阶级性 / 生产力变动 / 士的去向 / 被消音者
   - 哲学文本：自身框架的预设 / 论证的边界 / 被排除的可能性
   - 文学文本：被消音的人物声音 / 阶级视角的盲区 / 时代焦虑的掩盖
6. **时代焦虑**：他最担心什么、他的写作是不是在回应某个具体问题
7. **编排即判断**：
   - 把什么放在卷首
   - 把什么略写
   - 把什么浓墨重彩
   - 什么时候不直接评论（让事件自己说话）

### 5.2a 历史文本案例：作者档案（以司马光《资治通鉴》为例）

> **本节是案例**——按 §5.2 通用模板填充。具体作者档案应建立相应的作者档案。
> **重点**：下面所有"司马光"都是案例填充，不是规则本身。其他作者精读时，按 §5.2 通用模板建立自己的作者档案。

### 5.2a 历史文本案例：作者档案（以司马光《通鉴》为例）

### 5.3 其他领域的应用扩展

**哲学文本**：
- 症候阅读：揭示哲学家"看不见"的盲区（被问题域边界遮蔽的部分）
- 辩证法：揭示哲学论证从旧框架→新框架的扬弃过程
- 拉康精神分析：诊断哲学论证中"主体"的隐含位置（笛卡尔的我思 / 黑格尔的精神 / 海德格尔的此在 / 拉康的主体$）

**文学文本**：
- 症候阅读：揭示作者的阶级立场、问题域边界、被压住的人物声音
- 辩证法：揭示文学风格/流派从旧→新的扬弃过程
- 拉康精神分析：诊断文学人物的主体位置（哈姆雷特型 / 安娜·卡列尼娜型 / 各种人物）

**政治理论文本**：
- 症候阅读：揭示理论家的阶级立场、被压住的政治可能性
- 辩证法：揭示政治理论从旧→新的扬弃过程
- 拉康精神分析：诊断政治主体（领袖、群众、官僚）的主体位置

**通用规则**：任何领域的精读，都可以用"症候阅读读文本结构 / 辩证法读过程 / 拉康读主体位置"的三叉戟。

## 6. 整合使用后的"自检清单"

每卷精读完成后，对照以下清单自检（适用于任何领域）：

- [ ] **复合主轴声明**在卷首显式给出
- [ ] **跨域理论使用位置**在卷首显式列出
- [ ] **至少 60% 的锚点用两套以上理论**
- [ ] **至少 20% 的锚点用三套理论**
- [ ] **拉康精神分析的判断**有 2-3 个独立证据点
- [ ] **症候阅读的判断**区分了"有意省略"与"结构性盲区"
- [ ] **辩证法的判断**落实到"这一卷把过程推到了哪个新阶次"
- [ ] **没有贴标签**："糊涂蛋""骗子""阴谋家"等庸俗化措辞没有出现
- [ ] **没有替作者背书**：作者的概念框架被作为解剖对象，不是解释结论
- [ ] **没有堆元叙述**："读者指南""本文结构""按需阅读"等没有出现
- [ ] **没有堆元指导式操作化建议**："把××当作管理者自检表"等没有出现
- [ ] **没有哲学宣言式大词自嗨**："伟大的悲剧""历史的不可抗拒力量"等没有出现
- [ ] **没有绑死特定文本**：框架的通用规则适用，不是只针对某一本书
- [ ] **解读篇幅 ≥ 原文 5-10 倍**

## 7. 与 deep-reading skill 的协作

- **决策矩阵**：`historical-source-close-reading.md` 是历史文本的基础协议，但其他领域（哲学/文学/电工等）应加载对应的领域协议。
- **agent-role.md**：定义了 6 条边界 + 6 条自检清单 + 文件操作安全（本版本 v2.4.0+ 新增）——本框架不重复，只做补充。
- **symptomatic-reading.md / psychoanalytic-rereading.md**：是这两个方向模块的具体执行细则。本框架是它们的**整合使用手册**——告诉你什么时候用哪一套、用多少、怎么交叉使用。
- **reading-format-system.md §1**：历史风格格式的产出规范（原文/材料段在上 + 精读段落群在下）——其他格式（哲学/文学/电工/通用）的规范见 reading-format-system.md 的对应章节。

## 8. 一句话总纲

**用三套理论作为手术刀（症候阅读 / 黑格尔-谢林辩证法 / 拉康精神分析）解剖任何文本，但不贴标签——揭示作者自己都没意识到的东西，但理解他的局限而非审判他；写出像书一样可读的精读，但不让形式压倒内容。**

本框架适用于任何领域的精读任务——历史文本只是其中一个案例。
