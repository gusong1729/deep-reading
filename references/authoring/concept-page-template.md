# 概念页模板

存放位置：`wiki/concepts/<概念名>.md`（**跨域扁平**，不分领域目录）。

## Frontmatter（强制字段）

```yaml
---
title: 概念名
domain: [哲学]              # 跨域标签，可多个（古文/哲学/电工/计算机/...）
source: 《书名》第X章       # 来源引用，强制，可多来源
related: "[[相关概念A]], [[相关概念B]]"   # wikilinks 互链
tags: [标签1, 标签2]
status: seedling            # seedling | growing | mature
---
```

## 正文结构

```markdown
# 概念名

**是什么**：（一句话定义，读者不查原文也能懂）

## 为什么重要
（该概念在所属领域中的地位、解决什么问题）

## 关键要点
- 要点 1
- 要点 2

## 版本/争议
（不同作者/版本/学派的不同说法——同名跨书合并后的分歧记录）

## 遗留疑问
（待澄清问题，重读攻击点）
```

## 规则

1. **同名合并**：第二次读到同一概念不新建页，更新既有页并追加来源。
2. **来源引用强制**：正文每个论断可追溯到 source。
3. **跨域关联**：同一概念出现在多领域时，domain 写多个，related 指向跨域相关概念——跨域节点是知识图谱最有价值的节点。
4. **状态机**：seedling（初建）→ growing（补充中）→ mature（稳定可信）。Lint 时检查状态。
