# 全文精读协议（Full-Text Exegesis Protocol）

> 用户明确要求（2026-08-22）：**必须全文解读**，不是只解读难段。难段解读只是全文精读的一部分。
> 用户核心阅读哲学（2026-08-22 修正）：**阅读是线性跟随文本的过程，不是概念重组**。不从上下文阅读，文本就不可理解。精读必须**文本驱动**，不是概念驱动。

## 定位

精读 = **像人读书一样线性跟随全文**：从序言/第一章开始，逐页逐段推进，原文始终在场，解读逐句对应。概念解释只在文本流中自然出现时展开，绝不脱离文本重组。

## 全文覆盖要求（文本驱动）

- **线性顺序**：从序言/前言/第一章开始，按书的自然顺序推进，不跳段、不挑选。用户明确要求“从最开始的序言开始”。
- **原文在场**：解读的每一句都能在原文中找到对应——原文必须复制在上（逐句/逐层），读者始终看得见文本本身。
- **上下文即文本流**：一切解读挂在文本的线性上下文上——前文铺垫、后文呼应、全书位置。禁止脱离文本的“概念百科式”解读。
- **分批推进**：一次对话读一块（序言→代译序→前言→词条 A-Z…），持续直至全文完成，精读页状态才变为“已精读”。
- **进度可见**：精读页标注“已完成 X/Y”，index.md 同步。

## 每个词条/段落的解读结构(教科书式)

### 1. 逐句对应式解读(核心格式)

**原文逐句/逐层在上,解读逐句/逐层在下**--读者能一句一句跟着走,而不是读完一整段再看一段重构。

```
【原文】......(第 1 句)......
【解读】这句在说什么:......(指出阅读难点:翻译绕在哪、省略了什么、指代谁)

【原文】......(第 2 句)......
【解读】......
```

(不逐句时按"层"切分--一个意思层一组,但必须与原文顺序对应。)

### 2. 概念解释完整要素(每个关键术语必须包含)

1. **一句话定义**(读者能直接带走)
2. **来源与词源**(谁提出/哪个词/为什么不翻译)
3. **演变**(早期/中期/晚期含义变化--参考拉康词条演变史写法)
4. **体系位置**(这个概念在整理论图景中站哪、与相邻概念怎么咬合--概念互锁)
5. **临床/案例落地**(★ 优先用理论自身的临床案例与文本例证:拉康的个案、临床现象、文本实例--如享乐对应性冷淡/焦虑/施虐狂/阻抗;而非泛化的通俗比喻。理论必须回临床,这是专业解读的标准做法)
6. **常见误解**(读者最容易被绕进去的地方,主动指出)

> 参考范例(anysearch 检索 2026-08-22):Dra-M《原乐/享乐》--以演变史组织(首次出现→1958性化→1960伦理学)+ 概念互锁(原乐↔欲望↔焦虑↔阉割↔圣状)+ 临床落地(性冷淡、精神病焦虑、施虐狂、神经症阻抗)为模板。

### 3. 难段加深

遇到难点段落,按 exegesis-protocol.md 的学术级展开(上下文关联/概念溯源/学者分歧)。

## 铁律

1. **逐句对应优先**:解读必须与原文顺序一一对应,禁止"整段重构后讲一遍"
2. **具体现象不可缺**:每个抽象概念必须落到可感知的现象/例子/临床材料
3. **预判阅读难点**:主动指出"这句你会卡在哪、为什么"
4. **术语可放但要说清**:概念溯源允许,但服务于"说明白"--溯源完必须回到"所以这段到底在说什么"
5. **全文覆盖**:跳过任何词条/段落即不合格
6. **禁直觉类比**(继承):例子≠比喻;哲学不允许绕过概念抓直觉

## 落库

全文精读写入 `wiki/readings/<领域>/<书名>.md`,逐块追加。每块完成后更新进度标记与 index.md。
