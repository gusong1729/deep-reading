# 古文逐段精解模板

适用：文言文、古诗文、古籍（《文心雕龙》《诗经》等）。方向模块：**古文**。
特征：**逐段精解**——不逐句讲等于没读。

---

## 精读文档结构

```
# 《篇名/书名》精读

## 题解
（作者生平与时代、篇目在全书中的位置、核心主题、创作背景）

## 版本说明
（所用底本：中华书局/上古/其他；有无异文、句读说明）

## 逐段精解
（原文按段/句/章切分，每段重复以下结构）
```

### 每段结构

```
### 第 N 段

**原文**
> （原文照录，繁体/简体按底本）

**白话转述**
（逐句或整段白话翻译，务必通顺可独立阅读）

> [!note]
> **白话转述的选择性应用（2026-08-26 轮次 26 沉淀）**：白话转述只对**一手古文**做，对**二手导读笔记**不做（导读笔记已是现代汉语 / 白话，再做白话转述是冗余动作）。**判别标志**：照录文本是繁体 / 简体文言文 → 一手原文，必须做白话转述；现代汉语叙述 + 个人解读 → 二手导读笔记，不做白话转述。这是格式选择的精细化，详见 `reading-format-system.md` §4.5.b。

**逐句注释**
- 关键词训诂：字义、通假、异体字、古今异义
- 句法说明：特殊句式、省略、倒装

> [!note]
> **古音韵部判断的精度（2026-08-26 轮次 26 沉淀）**：古音韵部判断以王力《汉语史稿》《古汉语韵母系统研究》或同等量级工具书为准；不押韵时不得伪造押韵；如发现通押或转韵，按实际分部注音。**常见失误**：心（侵部）/寄（歌部）按现代汉语读音相近（-in/-i）但古音分部不同，不可强行判为押韵；其他按普通话 -n/-ng 收尾字易被误判为押韵（实际上古音分部严格按声母 + 韵母 + 声调三重区分）。

**深层解读**
（该段在全文中的作用、义理分析、修辞手法、文章结构上的功能）

**典故与背景**
（用典出处、历史人物/事件、文化语境、礼制/名物）

**历代注疏对照**
（毛传/郑笺/孔疏/集解，或近现代注家的不同说法与分歧点）

**学者评价**
（anysearch 检索历代学者/今人对此段的评价，注明出处）
```

## 收尾

```
## 本篇总评
（全文脉络回顾、思想主旨、文学史/学术史地位）

## 概念页清单
（本篇提取的概念 → 已建/待建 wiki/concepts 页）

## 遗留疑问
（尚不明确的训诂/义理问题，供下次重读攻击）
```

## 与全局铁律对齐（必读）

> 古文精读同样受 deep-reading 全局铁律约束（agent-role.md §2-§4）。模板六块是内容清单，不是输出格式——

- @规则: **叙述段落群，不分块标签**：白话转述、训诂、深层解读、注疏对照、学者评价五项必须融合成连贯的叙述段落群，逐段展开论述；禁止输出"白话：…/注释：…/解读：…"式的分块标签清单（agent-role §3 禁分块标签）。
- @规则: **原文比例**：解读篇幅 ≥ 原文 5 倍（1:5-1:10），绝不允许一段原文只配一段等长注释。
- @规则: **每段末尾一句操作化建议**：告诉读者"读这类古文遇到 X 时应该怎么处理"。
- @规则: **防误读段**：每段（或每组段）设"最容易读错的是…"，优先排查古今同形词（神、物、意象、虚静之类今义覆盖古义的词），给出"错读—正读"对子。
- @规则: **异文标注**：引文与今传本/底本有字面差异时（如《神思》引庄子作"形在江海"，今传本作"身在江海"），须标注版本差异并说明采用哪个版本及理由；引书改字处往往就是作者用意的所在。
- @规则: **骈文对偶即分类骨架**：骈文/对偶文本深层解读时，先画出对偶两翼、把每翼关键词写下，再读文采——对仗本身承担分类与论证功能（如《神思》两组对偶即思维四特征的骨架）。

- @规则: **骈文对偶即情绪节奏——反向动作（2026-08-26 轮次 26 沉淀）**：情感段（自序 / 序志 / 赠序 / 悼文 / 书信 / 私志）的骈文对偶多承担情绪节奏而非分类骨架。**判别标志**：自序 / 序志等情感文本 + 段内未出现分类词汇 + 情感化措辞主导；**判别标尺**：递进型对偶多承担情绪节奏，并列 + 对照型对偶多承担分类骨架。**失败模式**：按"分类骨架"读情感段的对偶，错失情绪节奏的修辞功能。详见 `reading-format-system.md` §4.5.c。

## 注意

- **训诂优先**：字义不清先解决字义，不做无根据发挥
- **注疏对照**：不同注家的分歧是精读最有价值的部分，必须呈现
- **学者评价至少一处并注明来源**：本地权威注本/研究著作（如杨明《文心雕龙精读》），或 anysearch/web 检索历代注家与今人研究；注明出处即可，不强制依赖在线检索（离线环境以本地权威著作为准）。
