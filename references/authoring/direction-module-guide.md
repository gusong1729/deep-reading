# 方向模块沉淀指南

当一次阅读使用了**通用模式**，或用户觉得某个学科的读法"不对味"时，按本指南把该学科沉淀为新方向模块。

## 触发时机

1. 用户主动要求："给 X 学科建个方向"
2. 通用模式精读完成后，agent 提示"本次阅读是否沉淀为新方向模块"，用户确认
3. 用户对精读产出提出方向性不满（"古文这样读不对，要逐句训诂"）

## 新建步骤

1. **定义触发特征**：该学科的文本特征（文体、术语、典型书名）与文件名规律
2. **选模板**：逐段精解型（需逐句解读的：古文、诗歌、条文）还是结构化解读型（需拆论证/结构的：论著、教材）
3. **定义概念字段差异**：该学科概念页需要什么特殊字段（古文：训诂/异文；电工：公式/国标）
4. **写模块文件**：新建 `references/<学科>-module.md`，含：
   - 触发特征清单
   - 模板选型与变体说明
   - 概念页字段差异
   - anysearch 检索策略（该学科优先搜什么）
5. **注册**：更新 SKILL.md「方向模块」表
6. **试运行**：用一篇真实文本跑通，根据产出质量迭代模块文件

## 模块文件骨架

```markdown
# <学科> 方向模块

## 触发特征
- 文本特征：...
- 文件名/关键词：...

## 模板选型
- 精读模板：<guwen-template / structured-template> + 变体说明

## 概念页字段差异
- 新增字段：...
- domain 标签值：<学科名>

## anysearch 检索策略
- 优先检索：...
```

## 原则

- **不修改核心六步流程**：模块只影响 Step 2 模板选型与 Step 5 概念页字段
- **模块是活的**：每次该学科精读后，若发现模板缺陷，当场修订模块文件
- **宁缺毋滥**：通用模式能胜任的学科不必沉淀模块；沉淀标准是"通用模式明显不够用"
