# deep-reading

给 AI Agent 用的全文精读技能。你给它一本书或一篇文章，它按固定规矩读完，输出一份能独立阅读的精读文档，并写进你的知识库。

适用：需要把长篇材料读透、留下可复查笔记的人。支持 PDF / EPUB / TXT / DOCX / MD / HTML，领域不限（历史、哲学、文学、政治、社会学、电工等）。

## 快速开始

1. 把 `deep-reading/` 放进 Agent 的 skills 目录（见「安装」）。
2. 准备一个知识库目录（见「知识库结构」），至少要有 `wiki/readings/`。
3. 对 Agent 说：**用 deep-reading 精读这本书**，并把文件交给它。

之后它会先选格式，再逐段产出「原文 + 解读」，最后把精读页、概念页、索引和日志一并写入知识库。

## 产出长什么样

JSON 最小合格单元是「原文锚点 + 解读段落群」：原文照录在上，解读紧随其下，解读篇幅不低于原文的 5–10 倍。下面是一段结构示意（非完整精读）：

> 原文：「知人者智，自知者明。胜人者有力，自胜者强。」——《道德经》第三十三章

老子把「智」与「明」、「力」与「强」分成两组，两组之间有高下。知人是朝外看，能看清别人的短长；自知是转身向内，把自己也当一个可被审视的对象。前者是能力，后者是位置的变化。同理，胜人靠的是对外较量的力气，自胜要处理的是自己内部的抵抗，后者没有旁观者，也没有终点。

这句话在《道德经》里不孤立。「明」字在全书反复出现，指向的都是同一种能力：不被表象牵走。放在第三十三章的上下文里看，它和「强行者有志」构成一组，整章谈的其实是持续性的问题，而不是一次性的胜负。

（其余格式与验收标准见 `references/authoring/reading-format-system.md`。）

## 特性

- **全文覆盖**：不跳段、不挑选，难点段落另外加深，不替代全文。
- **多格式适配**：通用论述、历史文本、电工实操、哲学、小说叙事、批判性文本六种格式，各自有最小合格单元与验收清单。
- **跨域分析**：症候阅读（阿尔都塞）、辩证法、拉康精神分析三套框架；另有面向政治史与当代史的「力量分析」模块。相关视角融入解读正文，不单独成节。
- **落库联动**：精读页、概念页、索引、操作日志同步更新，兼容 Obsidian 的 `[[wikilink]]`。
- **质量约束**：6 条写作边界与 6 条内容自检清单（事实、范围、陷阱、术语、排查顺序、多视角）。

## 安装

将 `deep-reading/` 目录放入 Agent 的 skills 目录，重新加载后生效。

| 平台 | 路径 |
|---|---|
| HanaAgent | `<工作区>/.agents/skills/deep-reading/` |
| Claude Code | `~/.claude/skills/deep-reading/` |

未触发时只加载 `name` 与 `description` 两行，触发后才读入完整内容。

## 知识库结构

本技能是执行器，产物需要落盘。最小结构：

```
<知识库>/
├── SCHEMA.md            规则层：目录结构、命名约定、Ingest / Query / Lint
├── raw/                 原文层（只读）
└── wiki/
    ├── index.md         内容索引：每页一行
    ├── log.md           操作日志
    ├── readings/        精读页，按领域分目录
    └── concepts/        概念页
```

未建库也能运行，但产出无处可存，等于一次性输出。

## 用法

| 输入 | 行为 |
|---|---|
| 「用 deep-reading 精读这本书」+ 文件 | 全篇精读：选格式、逐段解读、落库 |
| 「这段看不懂」/「解释这段」 | 难点细读 |
| 「我读到第三章没读懂」 | 答疑：先读索引，再定位页面 |
| 「Ingest 入库」/「体检知识库」 | 入库、更新索引、盘点矛盾与缺口 |
| 「继续往下写」 | 基于已有精读续写下一卷 |

## 已知限制

- 依赖知识库落盘；只装技能不建库，产出不会留存。
- 长文本开销大，整本书的精读通常需要分批推进。
- 精读质量取决于 Agent 对 references 规则的执行程度，建议对关键结论自行回原文核验。
- 不替代人工校对与判断。
