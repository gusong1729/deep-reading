# ADR-0007：难段深度解读协议（Exegesis Protocol）

用户明确需求：精读不是结构化定义，而是把难懂段落"讲成人话"。决策：新增 `references/exegesis-protocol.md` 协议——原文在上、解读在下；解读必须基于上下文讲清"这段在讲什么"；概念溯源必须结合本段语境；**禁止"直觉类比"**（哲学不允许绕过概念抓直觉）；触发方式为**用户手动指令**（不自动检测）；解读成果写回 `readings/` 精读页。

背景：现有精读（结构化术语簇）能组织知识，但无法满足"遇到难段→结合上下文理解→把意思说出来"的核心需求。用户对 Q3 推荐中的"类比抓直觉"明确否决（"哲学是不允许抓住直觉的"），以"概念溯源+上下文"取代。适用范围：全部方向（哲学/古文/电工）。
